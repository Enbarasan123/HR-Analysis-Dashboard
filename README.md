📊 **HR Analytics Dashboard Using Power BI | Data Analytics Project**

Excited to share my HR Analytics Dashboard developed using **Microsoft Power BI!** 🚀

This project focuses on analyzing employee data and transforming raw data into meaningful insights through interactive visualizations.

🔍 **Key Features:**

- Total Employees and Active Employees
- Employee Attrition Count and Attrition Rate
- Average Employee Age and Experience
- Attrition Analysis by Department
- Attrition Analysis by Salary Slab
- Job Role and Job Satisfaction Analysis
- Age Group Distribution
- Gender-wise Attrition Analysis
- Attrition Trends by Experience
- Department-wise Employee Count

🛠️ **Tools Used:**

- Microsoft Power BI
- Data Visualization
- Interactive Filters and Slicers
- HR Data Analysis

🎯 **Project Objective:**

To understand employee attrition patterns, identify workforce trends, and provide data-driven insights that can support better HR decision-making.

This project helped me strengthen my skills in data visualization, analytical thinking, and building interactive dashboards.
